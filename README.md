📦 API REST – Node.js e Express

Projeto desenvolvido para praticar a criação de uma API REST utilizando Node.js e Express.

A API permite realizar operações de CRUD (criar, consultar, alterar e excluir) para:

👤 Clientes
📦 Produtos
🛒 Itens
🧾 Pedidos
---
Os dados são armazenados em arquivos JSON, e o projeto foi organizado utilizando rotas e controllers.

Também foi criada a função calcTotais, responsável por calcular automaticamente o valor total dos pedidos, considerando o preço dos produtos e suas quantidades.
---

🛠️ Tecnologias utilizadas
Node.js
Express
JavaScript
JSON
Thunder Client
Git e GitHub
---
O projeto foi testado utilizando o Thunder Client, realizando requisições GET, POST, PUT e DELETE.
